
# Hi, I'm Akash Singh.

- **Databases:** PostgreSQL, MongoDB, Redis, ChromaDB
- **Infrastructure:** AWS, Docker, CI/CD, S3, EC2
- **AI/ML:** LLMs, RAG, hybrid search, BM25, vector databases, LangChain, LiveKit
